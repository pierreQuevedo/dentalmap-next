# Vignettes de cartes

Rendues par `scripts/design/cartes-villes.mjs` avec MapLibre sur le style « positron » d’OpenFreeMap.
Données © OpenStreetMap contributors, © OpenMapTiles. L’attribution doit rester visible là où ces images sont affichées.

Les vignettes de `departements/` sont rendues par `scripts/design/cartes-departements.mjs` ; les contours viennent de france-geojson.gregoiredavid.fr, eux aussi issus d'OpenStreetMap.
